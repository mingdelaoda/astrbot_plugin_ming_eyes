## 📖 简介

专为 AstrBot 打造的多模态视觉增强插件。拦截 QQ 聊天中的图片、动图（GIF）和短视频，支持“云端直传”与“本地抽帧”双通道。既能突破 QQ 的九宫格压缩限制，又能根据模型能力动态分配算力，极大地节省 Token 并保护本机性能。

## ✨ 核心功能
1. **多通道视频处理**：支持自动（智能识别）、强制本地（省流量防隐私）、强制云端（省算力）三种模式。
2. **GIF 九宫格重组**：识别被 QQ 压缩成 3x3 的静态动图，自动切割并按序重排为垂直连环画。
3. **本地视频抽帧**：支持本地 ffmpeg 按自定义帧率抽帧，拼成单张长图后注入模型（适合纯图片视觉模型）。
4. **动态模型解耦**：不写死模型，根据后台配置的 `vision_provider_id` 动态获取模型能力。
5. **完全自定义配置**：帧率、分辨率、触发词、处理通道全都可以在网页后台自由调节。

## 💡 懒人一键抄作业（用户场景推荐）

不知道怎么填参数？看看你是哪路人，对号入座：

*   🤖 **小白入门（必须配置一步）**：
    *   **第一步（必填）**：在 `vision_provider_id` 中填入你配置好的视觉提供商 ID（例如 `zhipu`）。如果不填，插件无法工作！
    *   **第二步**：`video_process_mode` 保持默认选 `auto`。
    *   **第三步**：`video_scale_width` 选 `480`。
    *   其他参数保持默认。只要填对提供商 ID，你就可以愉快地发图发视频了。
*   💰 **省钱的专用（精打细算）**：
    *   `video_process_mode` 选 `local`
    *   `video_scale_width` 选 `360`，`normal_fps` 填 `1` 或 `2`
    *   主打一个极限压缩、省流量、省 Token，只要能看个大概就行。
*   💻 **配置高的专用 / 大佬专用（本地狂飙）**：
    *   `video_process_mode` 选 `local`
    *   `video_scale_width` 填 `720`，`normal_fps` 填 `5`
    *   你的服务器内存最好 8G 以上，让 ffmpeg 在本地跑出电影级的画质，数据绝对不外传。
*   💎 **有钱的专用（云端氪金）**：
    *   `video_process_mode` 选 `cloud`
    *   完全无视本地配置，直接把原视频甩给大模型。主打一个算力外包，只要 API 额度管够，4K 画质随便看。

## 📦 安装
1. **环境要求**：AstrBot v4.29.3 及以上；若使用本地抽帧模式，容器内需安装 `ffmpeg`。
2. **放入目录**：将插件文件夹放入 `plugins/astrbot_plugin_ming_eyes`。
3. **安装依赖**：插件依赖 `Pillow` 和 `aiohttp`。若容器无 ffmpeg，请执行：`docker exec astrbot apt-get update && apt-get install -y ffmpeg`。
4. **重启生效**：重启 AstrBot，在网页后台确认插件状态为“已加载”。
5. **配置参数**：打开插件配置页，按下表填写。

## ⚙️ 配置项
| 参数 | 默认值 | 说明 | 建议范围 / 最高阈值 |
|---|---|---|---|
| `vision_provider_id` | （空）/（必填） | 视觉提供商 ID，插件据此调用对应的 API Key 和 URL | 字符串 |
| `video_process_mode` | auto | 视频处理通道。auto(自动白名单)/local(强制本地)/cloud(强制云端) | auto / local / cloud |
| `normal_fps` | 2 | 普通看图/动图的抽帧率 | 1 - 5 (**最高不建议超过 5**) |
| `deep_fps` | 5 | 触发高级指令时使用的暴力抽帧率 | 5 - 10 (**最高不建议超过 10**) |
| `high_mode_command` | #深度解析 | 触发高级性能模式的专属指令 | 字符串 |
| `video_scale_width` | 480 | 视频长图缩放宽度（高度自动等比缩放） | 360 - 720 (**最高建议不超过 1080**) |

## 🚨 免责与预警（必读）
1. **配置防爆**：参数请按自己机器的本事来！硬在 2核4G 的服务器上选 `local` 模式开 10帧 + 1080P，把服务器 CPU 跑冒烟了，请自行购买灭火器。
2. **模型验明**：请先确认接口支持视觉模态，别拿纯文本模型去喂视频，瞎了不赔。`glm-4v-flash` 只认图不认视频！
3. **数据流向与隐私**：本插件不收集您的任何聊天记录或额外隐私。数据处理去向取决于您选择的通道模式：
   *   **local（强制本地）**：视频会在本机的 `/tmp` 临时目录被切割拼接为长图。生成完毕后，**仅将长图**发送至云端大模型 API。中间文件在 24 小时内自动清掉。
   *   **cloud（强制云端）**：视频文件将直接通过 API 发送给云端大模型进行解析，本地不产生临时文件。
   *   **auto（自动模式）**：根据模型能力，按上述两种方式之一执行。
4. **密钥安全**：API Key 自己看好，泄露被刷余额，老板概不兜底。
5. **⚠️ 参数溢出警告（打破迷信）**：画质和帧率**绝非越高越好**！云端视觉模型底层会进行降采样（强压缩）。超过上述建议阈值的配置（如 4K、30帧），除了成倍榨干服务器 CPU 和 API Token 外，大模型实际看到的清晰度不会有任何提升。适可而止才是王道！
6. **⚠️ 第三方适配免责**：本插件按“原样”提供，不保证完美适配任何第三方魔改平台或特殊模型。若因您自行修改环境导致报错，请自行排查。拒绝“白嫖免费版却要求企业级定制服务”的伸手党。
